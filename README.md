# London PM2.5 Sensor Study

Field-based analysis of fine-particulate pollution collected with a portable Arduino environmental logger across contrasting London locations.

## Project design

Measurements were collected in the field and analysed in R to compare PM2.5 concentrations across locations and through time. The workflow includes data cleaning, descriptive statistics, confidence intervals, distributional comparisons and time-series visualisation.

## Repository contents

```text
code/AIRQUALITY.R          R analysis workflow
data/Airquality.csv        Analysis-ready measurements
data/DLFAIRLOGGER copy2.xlsx  Original logger export supplied for the project
figures/                   Final analytical figures
```

## Tools

Arduino environmental logger · R · field sampling · air-quality analysis · statistical visualisation

## Limitations

The study represents a limited field campaign rather than a regulatory monitoring network. Results reflect the sampled times, routes, local conditions and sensor performance. The Arduino firmware was not present in the local archive and is therefore not claimed as included source code.
